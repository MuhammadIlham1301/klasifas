Accessibility Policy: prefers-reduced-motion: reduce

Mandatory WCAG 2.2

Jika sistem operasi mendeteksi preferensi pengurangan gerak, seluruh animasi non-esensial, transformasi spasial (translasi X/Y), efek scaling, dan looping shimmer dinonaktifkan sepenuhnya (transform: none !important; animation: none !important;). Transisi interaksi bertumpu eksklusif pada transisi opasitas instan (maksimal 80ms) dengan jaminan zero layout shift (CLS = 0) guna mencegah disorientasi vestibular pengguna.

@media (prefers-reduced-motion: reduce) {
  * { transition-duration: 80ms !important; }
  * { transform: none !important; }
  * { animation-iteration-count: 1 !important; }
}

5. Ticket Workflow & 4 Official Statuses Transitions

State Mutation Protocol

Alur 4 Status Resmi Tiket Fasilitas FTII UHAMKA: Baru → Terverifikasi → Diproses → Selesai

Setiap mutasi status memperbarui audit trail secara real-time dengan transisi warna badge tenang tanpa getar berlebih.

info Prinsip Tata Kelola PRD: Penugasan teknisi dan pelaksanaan perbaikan fisik merupakan aksi dalam alur kerja (workflow actions), bukan nama status tiket tambahan.
1. Baru STEP 01

Tiket Diajukan

Tiket masuk dari civitas akademika FTII. Menunggu triase awal Admin Sarpras.

Workflow: Submit Form Pelapor (Fade-up 200ms)
2. Terverifikasi STEP 02

Disposisi Teknisi

Aksi alur: Admin Sarpras memvalidasi kategori & mendisposisikan penugasan teknisi.

Workflow: Assign Dialog Confirmation (Fade 150ms)
3. Diproses STEP 03

Perbaikan di Lokasi

Aksi alur: Teknisi tiba di lokasi Gedung FTII Lantai 1-4 dan melakukan perbaikan fisik.

Workflow: Checklist Lapangan (Fade-in 200ms)
check 4. Selesai STEP 04

Validasi Tuntas

Foto bukti perbaikan diunggah. Tiket diverifikasi selesai dan ditutup resmi oleh Admin Sarpras (tanpa tanda tangan digital).

Workflow: Verifikasi Sarpras (Calm Confirmation)
